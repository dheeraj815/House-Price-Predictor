# House Price Predictor & Real Estate Valuation ML

Machine learning real estate price prediction web application leveraging multi-feature regression modeling and interactive geospatial analytics.

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Streamlit](https://img.shields.io/badge/Streamlit-1.32%2B-FF4B4B?logo=streamlit&logoColor=white)](https://streamlit.io)
[![Author](https://img.shields.io/badge/Author-Dheeraj%20Muley-black?logo=github)](https://github.com/dheeraj815)

## Key Features
- **Multi-Feature Valuation Engine**: Analyzes square footage, bedrooms, bathrooms, location tiers, and build age
- **Supervised Regression Modeling**: Evaluates Linear Regression, Random Forest, and Gradient Boosting algorithms
- **Interactive Price Sensitivity**: Dynamic sliders for instant recalculation and comparative market analysis
- **Visual Analytics**: Feature correlation heatmaps and price distribution curves via Plotly
